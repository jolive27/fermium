# Data source

- **File:** `resonances0.dat` (raw, unchanged), converted to `d0.csv` by `prepare.py` (300 targets with a measured D0).
- **URL:** https://www-nds.iaea.org/RIPL-3/resonances/resonances0.dat (RIPL-3, "Resonances" segment).
- **Downloaded:** 2026-09-27 (curl, HTTP 200).
- **Publisher:** IAEA Nuclear Data Section, Reference Input Parameter Library RIPL-3.
- **Citation:** R. Capote et al., "RIPL – Reference Input Parameter Library for Calculation of Nuclear Reactions and Nuclear
  Data Evaluations", Nuclear Data Sheets **110**, 3107 (2009).
- **License:** freely available from the IAEA for research; cite the paper.
- **Formulas used (typed from the papers):** H. A. Bethe, Phys. Rev. **50**, 332 (1936) (Fermi-gas level density);
  A. Gilbert and A. G. W. Cameron, Can. J. Phys. **43**, 1446 (1965) (spin cut-off σ² = 0.0888 √(aU) A^(2/3), and the
  a ≈ A/8 MeV⁻¹ average behaviour with shell dips).
