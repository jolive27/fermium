# Data source

- **File:** `Pantheon+SH0ES.dat` (raw, unchanged; 1701 light curves), converted to `sne.csv` by `prepare.py`
  (the 1590 light curves with zHD > 0.01; four columns, same numbers).
- **URL:** https://raw.githubusercontent.com/PantheonPlusSH0ES/DataRelease/main/Pantheon%2B_Data/4_DISTANCES_AND_COVAR/Pantheon%2BSH0ES.dat
  (repository https://github.com/PantheonPlusSH0ES/DataRelease).
- **Downloaded:** 2026-09-27 (curl, HTTP 200).
- **Citation:** D. Scolnic et al., "The Pantheon+ Analysis: The Full Data Set and Light-curve Release", ApJ **938**, 113 (2022);
  D. Brout et al., "The Pantheon+ Analysis: Cosmological Constraints", ApJ **938**, 110 (2022).
- **License:** the repository has no license file; the data are the public release accompanying the papers above,
  used here for research with citation.
- **Published value compared:** flat ΛCDM from Pantheon+ supernovae alone, Ωm = 0.334 ± 0.018 (Brout et al. 2022,
  statistical and systematic covariance), typed from the paper.
