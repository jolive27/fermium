* **Wall** = whole process, median: includes interpreter/runtime startup, package loading and JIT/compilation.
* **Inner** = the program's own timer around the computation only, median. Julia runs the kernel once on a tiny problem first, so Inner excludes JIT time.
* **×Julia** = time / Julia time (lower is better; < 1 means faster than Julia).
